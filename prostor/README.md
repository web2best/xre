# ООО «ПРО СТОР» · Консорциум «ЭкоБОС»

Одностраничный сайт компании в стиле вёрстки ASHS +10 VIP CLUB. Контент взят из презентации
«Озеленение автомобильных дорог» (`docs/ecobos-presentation.pdf`) и прайс-листа питомника
(`docs/prostor-price.xlsx`).

```
index.html            страница (стили и скрипты внутри)
assets/img/           фото и схемы из презентации
assets/price.js       данные прайса — генерируется, вручную не править
docs/                 исходные презентация и прайс (ссылки «скачать» на странице)
tools/build_price.py  сборка assets/price.js из xlsx
```

## Обновить прайс

Положить новый файл в `docs/prostor-price.xlsx` и выполнить:

```
pip install openpyxl
python3 tools/build_price.py docs/prostor-price.xlsx --date 12.08.2025
```

Скрипт ожидает ту же структуру листа: группы и роды — строки с заливкой без цены,
позиции — A: номенклатура, M: характеристика, N: стоимость.

Страница статическая: работает с любого хостинга и при открытии файла локально.
