# VPN2BEST → Microsoft Store: план подачи

Состояние на 17.10.2026. Файл нужен, чтобы продолжить работу из любой сессии Claude
или другим человеком: всё, что решено и что осталось, записано здесь.

## Исходные данные

- Установщик собран на Inno Setup. На сайте лежит как `VPN2BEST-Setup.exe`, версия 5.1.5.
  Ставит программу в Program Files, создаёт ярлыки, удаляется через «Программы и компоненты».
- Store принимает EXE-установщик как есть (тип продукта «MSI or EXE app»), MSIX делать не нужно.
- Исходники установщика лежат в репозитории `vpn2best` на GitHub. Claude к нему пока не
  подключён: на репозиторий нужно установить Claude GitHub App (https://claude.ai/connect-github)
  и назвать точное `владелец/репозиторий`.
- Аккаунт разработчика в Partner Center оформлен на частное лицо.

## 1. Сертификат (главный блокер)

Требования Store к EXE/MSI:
- Store **не переподписывает** EXE/MSI, подписывает сам издатель.
- Сертификат должен выдать центр из Microsoft Trusted Root Program. Самоподписанный не подойдёт.
- Подписаны должны быть сам установщик и все `.exe`/`.dll` внутри, включая сторонние
  (например, отдельное ядро VPN). Свои и чужие бинарники подписываем своим сертификатом до сборки.

Где взять сертификат частному лицу из Израиля:
- **Azure Artifact Signing** (бывший Trusted Signing), самый дешёвый вариант. Но частным лицам
  он доступен только в США и Канаде, так что нам **не подходит**. Организациям из Израиля, по свежей версии
  страницы Microsoft, доступен. Вариант на случай, если появится зарегистрированная компания;
  перед этим перепроверить список стран на странице quickstart.
- **Коммерческий центр сертификации** (Certum, SSL.com, Sectigo и др.): сертификат подписи кода
  на физическое лицо. Центр проверяет личность по документам. С 2023 года ключ выдают только
  на USB-токене или в облачном хранилище. Для подписи при сборке удобнее облачный вариант
  (у SSL.com это eSigner, у Certum SimplySign).

Важно:
- Сертификат оформлять на того же человека, на кого зарегистрирован аккаунт в Partner Center.
- В окне контроля учётных записей (UAC) Windows покажет имя из сертификата, то есть имя этого
  человека, а не «VPN2BEST». Чтобы там было «VPN2BEST», нужна компания и сертификат на неё.
- Подпись ставить с меткой времени (`/tr ... /td sha256`), иначе после истечения сертификата
  подпись перестанет считаться действительной.

В Inno Setup (команда подписи зависит от выбранного центра сертификации):

```iss
[Setup]
SignTool=vpn2bestsign
SignedUninstaller=yes
```

```bat
ISCC.exe /Svpn2bestsign="signtool.exe sign /fd sha256 /tr <timestamp-url> /td sha256 /n $qИМЯ ИЗ СЕРТИФИКАТА$q $f" setup.iss
```

## 2. Visual C++ Runtime

Установщик обязан работать офлайн: во время установки **ничего не докачивать** (за это
отклоняют по правилу 10.2.9). Поэтому `vc_redist.x64.exe` кладём внутрь установщика:

```iss
[Files]
Source: "redist\vc_redist.x64.exe"; DestDir: "{tmp}"; Flags: deleteafterinstall

[Run]
Filename: "{tmp}\vc_redist.x64.exe"; Parameters: "/install /quiet /norestart"; \
  StatusMsg: "Установка Microsoft Visual C++ Runtime..."; Flags: waituntilterminated
```

Другой вариант: положить DLL рантайма (`vcruntime140.dll`, `msvcp140.dll` и т.д.) рядом с exe программы.

## 3. Издатель «VPN2BEST»

- Поменять `AppPublisher` (и при наличии `AppPublisherURL`, `VersionInfoCompany`) на VPN2BEST.
- **`AppId` не менять**, иначе новая версия встанет второй копией рядом со старой, а не обновит её.
- Папку с данными пользователей не трогать, чтобы у клиентов не пропали ключи.
- Влить ветку с правкой до сборки версии для Store, чтобы сайт и Store отдавали одинаковый файл.

## 4. Постоянная ссылка

- Только HTTPS, номер версии в имени файла: `https://<сайт>/download/VPN2BEST-Setup-5.1.5.exe`.
- Файл по этой ссылке **никогда не перезаписывать**. Новая версия — новый файл, новая ссылка
  и новая подача в Partner Center. Store сам EXE-программы не обновляет; обновления у
  уже установивших идут через механизм обновления самой программы, если он есть.
- Если репозиторий публичный, подойдут файлы GitHub Releases:
  `https://github.com/<владелец>/<репо>/releases/download/v5.1.5/VPN2BEST-Setup-5.1.5.exe`.
- `VPN2BEST-Setup.exe` для сайта остаётся как есть.

## 5. Подача в Partner Center

1. partner.microsoft.com → Apps and games → New product → **MSI or EXE app** → зарезервировать имя.
2. **Pricing and availability**: страны, цена (бесплатно), видимость.
3. **Properties**: категория, сайт, контакт поддержки, ссылка на политику конфиденциальности
   (VPN работает с сетевым трафиком пользователя, так что политика понадобится).
4. **Age ratings**: заполнить анкету.
5. **Packages**:
   - URL установщика из п. 4, архитектура x64, языки;
   - тихая установка: `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`;
   - коды возврата Inno Setup: `0` — успешно, `2` и `5` — отменено, `8` — нужна перезагрузка,
     остальные — ошибка.
6. **Store listings**: название, описание, скриншоты, логотип.
7. **Notes for certification**: коротко, что делает программа и что она ставит в систему
   (драйвер, служба), см. риски ниже.
8. Submit. Проверка обычно занимает несколько рабочих дней.

## Риски, которые стоит проверить заранее

- VPN-клиенты обычно ставят сетевой драйвер (TAP/Wintun) и/или службу Windows с правами
  администратора. Есть отзывы разработчиков других VPN (eduVPN), что из-за служб с повышенными
  правами были вопросы по правилам Store. Нужно выяснить, что именно ставит VPN2BEST, и
  объяснить это проверяющему в Notes for certification.
- Перед подачей поставить подписанный установщик на чистую Windows (виртуалку) командой
  `VPN2BEST-Setup-5.1.5.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`, проверить запуск,
  подключение и удаление через «Программы и компоненты».
